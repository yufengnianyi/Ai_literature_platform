Return JSON only:
{
  "groupSummary": "2-3 paragraph synthesis of all evidence for this sub-question",
  "clusters": [
    {
      "claimSummary": "normalized claim statement",
      "consistency": "CONSISTENT|CONFLICTING|INSUFFICIENT",
      "sourceDocuments": ["doc title 1", "doc title 2"]
    }
  ],
  "consistencyNotes": ["note about agreements, conflicts, uncertainty, or evidence gaps"]
}

Rules:
- Write every returned field in English. This is an internal canonical evidence layer; user-facing localization happens later.
- Synthesize across evidence items instead of listing them one by one.
