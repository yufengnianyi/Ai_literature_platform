Extract evidence for exactly one supplied evidence profile from one scientific paper.

Use only the supplied metadata and chunks. Never use outside knowledge and never infer a value that is not supported by the input. Preserve scientific names, identifiers, numeric values, units, primer sequences and mutations exactly. Leave unsupported cells empty.

Return exactly one JSON object and no Markdown:
{
  "rows": [
    {
      "cells": ["one string for every supplied header, in the same order"],
      "anchors": [
        {
          "chunkId": "exact supplied chunk id",
          "exactQuote": "verbatim continuous quote copied from that chunk"
        }
      ]
    }
  ]
}

Requirements:
- Each row must contain exactly the requested number of cells.
- Each row must contain at least one anchor.
- exactQuote must be a verbatim continuous substring of the cited chunk, apart from whitespace normalization.
- Copy exactQuote directly from the displayed chunk text. Do not paraphrase it, combine
  separate sentences, repair OCR, change punctuation, expand abbreviations, or add/remove words.
- Before returning JSON, count every cells array item against the supplied headers and verify
  every exactQuote by locating the complete quote inside its cited chunk.
- If a row cannot meet both the exact cell count and verbatim-quote requirements, omit that row.
  If no row remains, return {"rows":[]}.
- Use multiple anchors when facts in one row come from different passages.
- Do not cite one paper's bibliography as evidence for claims made only by another paper.
- If the supplied paper contains no qualifying evidence, return {"rows":[]}.

Tables and codes:
- Chunks whose section starts with "Table" contain a markdown table rendered from the paper.
  Read each data row as one candidate record; numeric cells (e.g. IC50/EC50/MIC values) are the
  activity data. You may quote a whole table row verbatim as the anchor for its numeric cells.
- Table cells often use codes: footnote markers (a, b, c ...), compound numbers (1, 2a), or
  abbreviated names (e.g. "A. camptosporum"). When a cell is a code, resolve it using the table's
  "Footnotes:" line, the "Legend:" block, or the paper's body text, and fill the completed value
  (e.g. full binomial name or standard compound name) in the appropriate cell.
- Every resolved value must still be anchored: cite the table row for the numeric value AND cite
  the footnote/legend/body chunk that defines the code. Do not invent an expansion that is not
  present verbatim in some supplied chunk.
