# 领域问题分层归纳方案

日期：2026-09-14。状态：基于百篇实验及 Q1–Q10 提取规范的设计建议，含助手整理的真实案例；尚未实现或运行新模型流程。

## 1. 本轮决策

- 方案 A（直接摘要聚类）退出后续方案选择与实验，不再投入调参和新增运行。已有代码和实验产物保留供历史复现。
- 方案 B 保留逐篇问题与原文证据，后续改为“研究目的抽象、全局目录归纳、逐条归属、按证据总结”。下文称为 B2。
- Q1–Q10 暂作为抽象层级、问题边界和证据组织的参考。类别由当前语料产生，不固定十类。若后续明确采用专家目录，应单列为专家框架引导的分类方案。
- 本轮交付设计，不修改运行算法或调用付费模型。当前命令行仍为旧版实验实现。

另有语料范围问题：输出中出现花粉管、农民施药决策、水生生态等方向。仅凭主题名不能直接判定它们不相关，但需要逐篇确认与本次研究范围的关系。范围不明与真正的新方向必须分开，不能都并入某个卵菌机制类别。

## 3. 从 Q1–Q10 学到什么

[Q1 提取规范](../src/main/resources/prompts/evidence/q1-extraction-system.txt) 的上层问题是抗卵菌活性物质，底层一行则是“化合物/提取物/混合物 × 卵菌 × 实验方法”。化合物、来源、结构、活性、机制和安全性成为证据字段。浓度、时间与具体物种的变化不需要自动变成新的顶层目录。

建议明确四个层级：

| 层级 | 作用 | Q1 风格示例 |
| --- | --- | --- |
| 一级研究问题 | 跨文献反复出现、可以组织持续积累的研究目的 | 哪些物质具有抗卵菌活性，其作用机制与应用条件是什么？ |
| 二级子问题 | 将不同目的或证据任务区分开 | 活性与谱系、构效关系、作用机制、安全性、协同与抗性 |
| 比较维度 | 记录同一问题内的变化，可筛选或制表 | 化合物来源与结构、病原、宿主、试验场景、浓度、终点 |
| 具体证据 | 保存某项研究实际问了什么、发现了什么 | 某化合物在某条件下对某病原的观测与原文定位 |

比较维度不是固定的第三层分类树。例如“植物来源”与“菌丝生长抑制”是两个可交叉的维度，不宜并列成为互斥一级类别。

Q1–Q10 展示了不同问题需要不同字段，以下仅为参照表，不是 B2 的预置目录：

| 参考 | 可借鉴的上层目的 | 保留在证据或比较维度中的差异 |
| --- | --- | --- |
| Q1 | 发现并评价抗卵菌活性物质 | 化合物、结构、来源、病原、方法、活性、机制、安全性 |
| Q2 | 理解效应子如何作用于宿主 | 效应子、宿主靶标、识别、分泌转运、功能与结构证据 |
| Q3 | 理解并利用植物抗性 | 植物、基因/QTL、抗性类型、病原谱、验证与育种应用 |
| Q4 | 解释药剂抗性及靶标变化 | 药剂、靶标、突变、抗性水平、交叉抗性、检测 |
| Q5 | 描述基因组组成与变异资源 | 物种、菌株、组装版本、基因组指标、效应子组成 |
| Q6 | 解释病原自身的基因功能与调控 | 基因、发育过程、代谢、环境条件、表型、验证 |
| Q7 | 评价生防及绿色防控措施 | 防控因子、施用方式、病原、体外/植株/田间场景 |
| Q8 | 建立与评价诊断检测方法 | 靶标、技术、样本、检出限、特异性、实际验证 |
| Q9 | 解释流行过程并预测风险 | 环境变量、病害、模型、预测目标、验证范围 |
| Q10 | 解释小种、群体多样性及演化 | 病原、宿主、地区、群体、遗传与毒力变化 |

这些问题有交叉。化合物的细胞毒性、病原抗药性、植物宿主抗病性需要保持不同语义；一个基因有致病力表型也不自动成为宿主导向效应子。不能仅因字段形式相似就合并研究目的。

## 4. 建议的 B2 流程

```text
原始摘要与固定文献清单
  -> 质量、研究范围与证据角色检查
  -> 逐篇研究目的卡片：具体问题 + 抽象目的 + 变量 + 已报告结果 + 来源
  -> 全局归纳一级问题、二级子问题及比较维度
  -> 将全部原始问题逐条映射回目录，处理交叉、遗漏和不适配
  -> 汇集各子问题的结果证据，生成综合总结与比较表
  -> 原文追溯、覆盖检查、人工修改与目录版本记录
```

### 4.1 先分开研究目的与实例细节

保留原问题，例如“烷基取代基对椭圆碱类化合物抑制致病疫霉活性的影响是什么？”，同时派生“结构修饰如何影响候选物的抗卵菌活性？”这样的上层表达。

卡片包含：

- 原始问题及问题 ID、文献 ID。
- 研究目的与关注关系，例如“结构修饰影响抑制活性”。
- 对象的角色与具体值，例如候选物、目标病原、宿主、受测细胞；每个角色都保留原文依据。
- 试验或分析场景、观测终点、条件；摘要未给出的内容保持缺失。
- 结果主张、原文证据 ID，以及结果、推测、背景或方法描述等角色。
- 研究范围状态与抽取状态。

上层表达保留决定研究目的的概念；具体化合物编号、菌株编号、地区和剂量放入变量。不能把所有实体替换成通用占位符，从而失去“病原抑制”和“宿主毒性”的区别。

同一目的下的实验条件变化可以合成一张卡片并保留全部原问题映射。一个“鉴定到某物质”的事实不必再改写成独立研究问题；但如果结构鉴定本身是研究目标，仍保留其子问题身份。

### 4.2 让模型看到整个目录

当前只有 229 个问题，可先对全部精简卡片做一次全局候选目录归纳；调用前按实际模型上下文限制计量。完整摘要和证据保留在底层，需要判断成员归属或写结果主张时回取。

输入超过预算时，分批提出候选问题定义，再对候选定义进行全局合并，并将所有原始卡片重新映射。分批不能直接生成各自独立的最终目录。候选始终保留对应原问题 ID，防止中间摘要遗漏少数方向。

每个目录条目应包含：上层问题、纳入/排除定义、子问题、比较维度、代表性原问题、支持文献集合和待审状态。条目数由语料和这些定义决定，不预设为十，也不由单一距离阈值决定。

向量可用来召回相近卡片或建议可能重复的目录条目。最终归属需要依据研究目的与目录定义判断。

### 4.3 用明确规则控制粒度

| 情况 | 处理 |
| --- | --- |
| 目的相同，差异是化合物、基因、病原、地点或条件的取值 | 优先进入同一上层问题，将差异保留为子问题或比较维度 |
| 对象相同，目的分别为遗传图谱、群体繁殖和感染表达 | 分配到不同子问题或上层问题，不用物种名统称它们 |
| 相关但需要不同证据任务，如活性筛选与细胞毒性 | 同一研究问题下保留不同子问题，分别引用证据 |
| 同一篇论文回答多个上层问题 | 以问题/主张为单位多标签关联；每个关联必须说明贡献 |
| 单篇、低频或不适配现有目录 | 保留独立候选及原文，不为减少数量强制合并；是否提升为上层问题取决于目的独立性 |
| 声称新类别只是现有字段的另一个取值 | 保留为变量，通常不新增一级类 |

“更换具体化合物后，这个研究目的是否仍成立？”可作为抽象检查；“合并后是否还能明确说出这些文献在共同回答什么？”可作为过宽检查。都需要结合原文，不能替代证据核验。

父问题的定义是共同组织范围，并不要求每篇论文回答所有子问题。例如有些文献只支持活性子问题，有些同时支持构效和安全性。归属关系与某项结论的证据支持关系分别记录。

### 4.4 增加真正的结果综合

每个上层问题输出一段可读总结，至少说明：当前材料报告了哪些发现、主要差异是什么、哪些结果尚不能直接比较，以及有哪些原文明确指出的局限。

问题句本身不能作为结果证据。必须从摘要重新提取结果主张；需要完整数值、实验方法和对照时，再接入 Q1–Q10 风格的全文/表格提取。

每个总结句关联具体主张 ID、文献 ID 与原文位置。模型返回预先生成的句段 ID，由程序取回原文；有效 ID 仍需检查语义支持和对应主体，不能把“引用存在”当作“结论成立”。

合并同类研究目的不等于合并数值结果。跨文献比较需核对指标、单位、物种/菌株、场景与条件。摘要没有报告某项验证，只能记为“当前摘要未提供”，不能推断整个研究未做，更不能认定该领域存在空白。

## 5. 用本轮四篇化合物文献演示

以下是助手根据实际摘要整理的设计示例，不是 B2 模型输出或专家验收。四个旧簇共 4 篇文献、11 个原问题，均来自同一份 [B 聚类结果](../problem_discovery/outputs/real-run-100-20260914/question/clusters.json)。

一级问题建议表述为：**哪些物质具有抗卵菌活性，结构变化、作用机制与安全性证据如何？**

| 原簇及文献 ID | 摘要支持的内容 | 在新目录中的贡献 |
| --- | --- | --- |
| `c027`；`403fb7f6-6146-417d-b736-ce9277d8959d` | 月桂酸抑制大豆疫霉，摘要报告膜损伤及发育过程影响；LA/GML 在给定施用条件下对大豆植株的安全性 | 活性、机制、植物安全性；来源成为比较字段 |
| `c047`；`6154a78f-7efe-4a8c-8f27-936b03de1246` | flufuran 来自黄曲霉培养滤液；在 0.2 mg/ml 下对三种疫霉测试，摘要报告活性并突出乙酰衍生物 | 活性、结构衍生化；来源与鉴定方法进入字段，具体鉴定问题仍可回查 |
| `c054`；`6e88a8b8-11b7-4ea1-9815-3aab62c208fa` | 扁桃酰胺类似物针对晚疫病和葡萄霜霉病，摘要报告高效活性及构效关系研究 | 活性、构效关系；该摘要没有给出具体构效结论，不能自行补充 |
| `c055`；`70c3aa0e-11dd-4397-90c0-0d49a9aeeaa1` | 椭圆碱及衍生物抑制致病疫霉；研究烷基部分，摘要报告部分盐类衍生物的活性与受测人细胞系毒性表现 | 活性、结构优化、细胞安全性；受测细胞结论不扩大成普遍安全 |

可呈现的综合文字示例：

> 这四篇材料共同涉及候选物及其衍生物的抗卵菌活性。月桂酸研究报告了大豆疫霉膜损伤及相关发育过程的影响；flufuran 与椭圆碱研究将衍生化和候选物筛选联系起来，扁桃酰胺研究也报告开展了构效关系分析。安全性证据的对象不同：月桂酸/GML 研究的是给定施用条件下的大豆植株，椭圆碱研究涉及受测人细胞系。现有摘要提供的指标与条件不完整，因此尚不能据此给这些化合物作统一活性排序。

上段各分句的依据依次来自表中 `c027`、`c047/c055/c054`、`c027/c055` 的摘要；末句是对这四份摘要可比性的判断。实现时拆成逐句证据映射，不能只在整段末尾放四篇参考文献。

这四篇示例的上层范围覆盖 11 个原问题，但没有宣称每篇都回答机制、构效和安全性；原问题仍保留，以免归纳时丢失结构鉴定或历史身份判断等次要内容。

### 5.1 防止过宽合并的反例

旧 `c057` 把遗传连锁图谱、群体有性繁殖和 `ipiB/ipiO` 表达放在“致病疫霉”下。应分别按遗传资源、群体演化和基因表达的实际目的归属，不能仅因为研究同一物种就把结果综合成一个共同结论。

旧 `c082` 包含基因编辑方法与激发素基因研究；同一基因编辑文献的其他问题又进入 `c083/c084`。新流程可将同一文献中编辑方案、适用范围和转化方法聚合为方法类候选，并单独处理功能/序列研究。能否形成独立上层“研究工具”类别，还需看全体材料的支持与目录边界。

## 6. 下一次实验怎样开展

1. **先复用旧数据验证归纳层。** 对当前 229 个问题及对应摘要生成卡片、分层目录、成员映射和综合总结。保留原 100 篇清单，12 篇信息不足与 1 篇提取失败仍进入覆盖统计。
2. **将输入清理单独记录。** 首次对照使用相同语料范围；若过滤范围外材料或修复摘要，应另列处理后的结果，并在相同处理后的语料上比较旧 B 与 B2。不要把清理效果归因于归纳算法。
3. **比较旧 B 与 B2。** 评价上层目的是否清楚、同目的是否被拆散、不同目的是否混合、原问题是否遗漏，以及总结是否忠实、专家需要多少合并/拆分和整理时间。
4. **用固定案例查明显回归。** 四篇化合物应能共享上层范围并区分结果类型；`c057` 的不同目的不能被物种名掩盖；`c082/c083/c084` 应能识别方法与功能研究的差异。
5. **再扩到独立语料。** 当前百篇及上述示例已参与设计，属于开发材料。参数和定义冻结后，使用未参与设计的文献评价，分别报告新方向保留、覆盖和稳定性。

评价统计应包括：全部输入文献、可用卡片、已归属/待定/失败记录；上层与子问题数量；去重文献覆盖；分层抽样的归属准确性、碎片化与错误合并；逐句证据支持及人工整理时间。多标签下各类文献数可相加超过总数，总覆盖使用去重并集。

一级类别减少只是可读性变化，不能单独作为成功标准。也不采用“必须合并到十类”或“提高跨文献组比例即可通过”的门槛。

首个实现建议集中在独立 `problem_discovery` 原型中，新增卡片、目录、映射和总结产物，复用来源与缓存机制。待归纳效果确定后，再接 Java 流程和全文证据抽取。这里列的是待实施范围，并非当前已交付功能。

## 7. 方法依据与限制

TopicGPT 展示了使用大模型生成自然语言主题及描述，并允许约束与修订的主题建模方向，可参考其主题生成与分配的组织方式。[TopicGPT，NAACL 2024](https://aclanthology.org/2024.naacl-long.164/)

BERTopic 官方文档提供层次主题组织，说明细主题可以有不同层级的呈现；这些层次本身并不能证明目录符合本项目的研究目的与证据要求。[BERTopic 层次主题文档](https://maartengr.github.io/BERTopic/getting_started/hierarchicaltopics/hierarchicaltopics.html)

B2 的“研究目的、比较维度、证据综合”是结合本项目输出与 Q1–Q10 规范提出的设计推断；上述方法没有替本项目验证其有效性。Q1–Q10 作为专家预置框架时，应如实说明先验来源；作为参考时，也不能因为新目录接近十类就宣称自动恢复了领域全貌。
